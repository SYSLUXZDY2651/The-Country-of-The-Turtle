# The-Country-of-The-Turtle
A Game By Sakixl Game Studio,The game is about a Turtle's story.Enjoy it!

## ✨ Features

* 🐢 Control a Turtle
* ⌨️ Keyboard movement
* 🎨 interact with objects
* 🏠 Build and explore a Turtle environment
* 🕹️ Beat (hard or easy) levels and unlock (sometimes crazy) endings
* 📚 Made with beginner-friendly Python

* ## 🛠️ Built With

* **Python**
* **Turtle Graphics**
* **Pygame Graphics**
* Python's built-in libraries

* ## 🚀 How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Download the project

Clone this repository or download the files.

```bash
git clone https://github.com/SaiyaoYinIsNiuBi/py-turtle-simulator.git
```

### 3. Run the program

Open the main Python file and run it:

```bash
python main.py
```

You can also run it using **IDLE** by opening the Python file and selecting **Run → Run Module**.

## 🎮 Controls

| Key | Action     |
| --- | ---------- |
| `W` | Move up    |
| `A` | Move left  |
| `S` | Move down  |
| `D` | Move right |
